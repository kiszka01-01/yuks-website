---

## 🚀 Про проєкт
**YUKS** — це преміальна цифрова екосистема, створена для того, щоб показувати реальні рішення бізнесу через чистий, швидкий та естетичний код. Жодних зайвих абонплат за конструктори — лише чистий HTML5, Tailwind CSS та інтерактивний JavaScript.

### 💎 Головні фішки сайту:
* **Dark Luxury / Obsidian Дизайн:** Глибокий антрацит (`#08090C`), матові плашки (`#11141D`), акценти смарагдово-салатового або золотого неону та тонка геометрія Glassmorphism.
* **3D Tilt & Glass ефекти:** Картки та віджети реагують на рух курсору в тривимірному просторі.
* **Живі міні-вікна (Interactive Showcase):** Інтерактивні симулятори Telegram-бота, мобільних додатків для виїзних команд (PWA) та локального бустера Google Maps.
* **Інтерактивний слайдер «До / Після»:** Наочна демонстрація трансформації застарілих сайтів-хаосу у чисті та ефективні рішення.
* **ШІ-Консультант:** Інтерактивний асистент у шапці сайту, який спілкується з замовником та допомагає обрати ідеальний формат.
* **Пасхалки для своїх:** Секретні команди (Konami-код) та консольні привітання для колег-розробників.

---

## 🛠 Технологічний стек
* **Frontend:** HTML5, Tailwind CSS (CDN), Vanilla JavaScript (ES6+).
* **Інтеграції:** Telegram Web Apps API, Google Maps API, локальна база даних (localStorage) для веб-додатків.
* **Хостинг та деплой:** GitHub (джерело коду) + Vercel (миттєвий деплой).
